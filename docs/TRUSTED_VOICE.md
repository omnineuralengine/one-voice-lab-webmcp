# Trusted Voice: Familiar Care

Trusted Voice demonstrates a consent-first use of Deepgram Aura text-to-speech for routine institutional communication. The experience subtitle is **Familiar Care**.

> Familiar should never mean deceptive.

The module uses only the application's existing Deepgram Aura model catalog. It does not enroll speakers, create personal speaker profiles, or reproduce a particular person's voice. The intended result is an automated familiar-care message whose synthetic nature, fallback channel, and opt-out path are clear to the recipient.

## Scenarios

| Scenario | Risk | Default fallback | Default privacy posture |
|---|---:|---|---|
| Family Memory Reminder | High | Human callback | No private family or health details in open delivery |
| Medication Pickup Reminder | Medium | Verified mobile app | No medication names or diagnoses aloud by default |
| Healthcare Appointment Reminder | Medium | Secure portal | Minimum reminder details; private details in the secure channel |
| Financial Fraud Alert | High | Verified mobile app | No card numbers, codes, balances, passwords, or account secrets |

Loading a scenario only fills the builder. It never generates or plays audio.

## Execution boundary

The client builds the disclosure, message, fallback, and opt-out text, but the server independently validates scenario risk, consent confirmations, disclosure style, sensitive-detail policy, fallback, opt-out, text length, and hosted reviewer authorization before it calls Deepgram. `DEEPGRAM_API_KEY` remains server-only.

Generated bytes are fetched into a browser object URL and immediately deleted from the short-lived server handoff cache. A hard five-minute server timer removes the handoff if browser cleanup is interrupted. The browser URL is revoked on replacement, clear, reset, or unmount. Audio is not autoplayed or persisted by default.

Known limitation: sensitive-detail detection is a conservative heuristic. It cannot identify every medication, diagnosis, identifier, or contextual privacy risk. Human template review remains necessary.
